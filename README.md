# BugVault

BugVault is an ongoing full-stack application for organizing bugs,
solutions, and technical knowledge across software projects.

## Tech Stack

- Laravel 13 / PHP
- React 19
- TypeScript
- Inertia.js
- Tailwind CSS
- MySQL

## Current Features

- User authentication
- Project dashboard
- Project-scoped bugs
- Bug detail pages
- Authorization and typed frontend data

## Status

Currently under active development.
